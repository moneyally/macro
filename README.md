# ⚡ 매크로 PRO

밀리초 정밀 키보드·마우스 매크로 (Windows). 여러 매크로를 만들어 단축키로 돌리고,
녹화/편집/반복/문구 타이핑/붙여넣기/이미지 조건/창 조절/여러 방 동시 전송/예약·체인까지 되는 개인용 자동화 도구.

> ⚠️ 매크로 탐지하는 게임·프로그램엔 쓰지 마세요(계정 정지 위험). 일반 반복작업용입니다.

---

## 빠른 시작 (3줄 요약)
1. **＋ 추가**로 매크로 하나 만들고 → **✎ 편집**에서 동작을 쌓거나 **● 기록**으로 직접 녹화.
2. 그 매크로에 **실행 단축키**(예 `f1`)를 적어 둔다.
3. **F12**로 "실행 모드"로 바꾸면 → 이제 `f1` 누를 때마다 그 매크로가 돈다. 멈추려면 **F10** 또는 **■ 정지**.

> 작업한 내용은 **자동 저장**돼서 꺼도 안 날아감. 따로 보관하려면 **💾 저장**(.m 파일).

---

## 화면 설명

### 📋 매크로 목록
- **● 기록**: 지금 선택한 매크로에 키보드·마우스를 **녹화**(다시 누르거나 F9로 정지).
- **＋ 추가 / ⧉ 복사 / 🗑 삭제 / ▲▼**: 매크로 만들기·복제·지우기·순서.
- **✎ 편집**: 그 매크로의 **동작 목록**을 직접 보고 고침(아래 "동작 편집").

### 🎛 선택 매크로 (그 매크로만의 설정)
- **실행 단축키**: `f1`, `f2`, `ctrl` 같은 거. 실행 모드(F12)에서 이 키로 발동.
- **반복(0=무한)**: 몇 번 돌릴지. `0`이면 정지할 때까지 무한.
- **배속**: `2.0`이면 2배 빠르게, `0.5`면 느리게.
- **▶ 테스트 실행**: 편집 모드에서 바로 한 번 돌려보기.
- **🔗 끝나면 실행할 매크로**: 이 매크로가 끝나면 **이어서 다른 매크로**를 자동 실행(체인). 이름을 적으면 됨. (A→B→A 같은 무한 꼬임은 자동으로 막음)
- **⏰ 매일 자동 실행 (HH:MM)**: 예) `09:30` 적어두고 **실행 모드(F12)**로 두면 매일 그 시각에 자동으로 돎.

### ⚙ 전역 설정 (모든 매크로 공통)
- **이벤트 실행 주기(ms)**: 동작 사이 최소 간격.
- **타이밍 랜덤 ±%**: 간격을 매번 조금씩 흔들어 더 사람처럼.
- **🎲 동작마다 랜덤 대기(ms) 최소~최대**: 동작마다 랜덤으로 더 쉼(예 `50`~`200`) → 훨씬 사람같이.
- **한/영(IME) 감지**: 실행 중 영문 고정(문구 타이핑 깨짐 방지).
- **종료 시 눌린 키·버튼 모두 떼기**: 켜두면 정지할 때 누른 채였던 키를 안전하게 뗌.
- **종료 시 마우스 위치 복구**: 끝나면 원래 마우스 자리로.
- **녹화할 때 마우스 '이동'도 기록**: 끄면 클릭만 기록(파일 가벼움).

### 아래 버튼
- **💾 저장 / 📂 불러오기**: `.m` 파일로 매크로 묶음 저장·불러오기.
- **📜 기록**: 언제 어떤 매크로를 몇 번 돌렸는지 실행 기록.
- **■ 정지 / 종료**.

## 동작 편집 (✎ 편집 창)
동작을 위에서 아래로 하나씩 실행함. **➕ 동작 추가**에서 종류를 고르고 값 넣고 추가.

| 종류 | 설명 | 넣는 값 |
|---|---|---|
| 🖱 클릭 | 좌표를 클릭 | `좌표 x,y` · 버튼 `left/right/middle` · `횟수(,흔들기px)` |
| ✎ 문구 입력 | 글자를 타이핑 | 문구 · 초당 글자수(0=즉시) · 앞 대기(ms) |
| 📋 붙여넣기(빠름) | 복사→Ctrl+V | **긴 글·공지에 최고.** 한 글자씩 안 치고 한 번에, 한글·특수문자 안 깨짐 |
| 🔑 단축키 | 조합키 | `ctrl+c`, `alt+tab`, `ctrl+shift+s` |
| ➡ 이동 | 마우스만 이동 | 좌표 x,y · 걸리는 시간(초,0=순간) |
| ⏱ 대기 | 쉬기 | 밀리초(ms) |
| 🖲 스크롤 | 휠 | 양(+위/−아래) |
| 🖼 이미지 보이면 클릭 | 화면에 그 그림이 **있으면** 그 자리 클릭, 없으면 그냥 넘어감 | 이미지 .png · 정확도 0~1 · 버튼 |
| ⏳ 이미지 뜰 때까지 | 그림이 **나타날 때까지 대기**(로딩 기다리기) | 이미지 .png · 정확도 · 최대 대기(초) |
| 🔀 이미지 조건 | 조건 안 맞으면 **다음 N개 동작 건너뛰기** | 이미지 .png · `found`(있을때) / `notfound`(없을때) · 건너뛸 수 |
| 🪟 창 조절 | 창 제목으로 찾아 띄우기/옮기기 | 제목(일부) · `activate/min/max/close/move/resize` · move=`x,y` resize=`w,h` |

- **📍 좌표 찍기 (F8)**: 입력 대신, 원하는 위치에 마우스 올리고 **F8** 누르면 좌표가 자동으로 들어감.
- **🎯 연속 찍기**: F8을 **누를 때마다 그 자리 클릭 동작**이 계속 추가됨(여러 군데 찍을 때).
- **📡 멀티 타겟 (여러 방)**: 아래 설명.
- **● 이 매크로에 녹화 / ▲▼ / 🗑 삭제**.

### 📡 멀티 타겟 (여러 방에 한 번에)
방(채팅창)들을 등록해 두고 **공통 문구**를 쓰면, 한 번 실행에 **모든 방에 [클릭→입력→엔터]** 를 쭉 돌림.
1. **방 위치 찍기**: 📍 F8로 각 방 입력칸 위치를 찍거나(🎯 연속), 또는 **창 제목으로** 추가(창이 겹쳐 있어도 안 밀림 — 추천).
2. **공통 문구** 입력.
3. 옵션: 입력 후 엔터(전송)·타이핑 속도·방 사이 간격(ms)·클릭 후 대기(ms).
4. **➕ 이 매크로에 멀티타겟 추가** → 동작 하나로 들어감.

## 단축키
`F8` 좌표 찍기 · `F9` 녹화 시작/정지 · `F10` 정지 · `F12` 실행↔편집 전환

## 밀리초 정밀 (왜 정확한가)
`perf_counter`(마이크로초급) + Windows 타이머 1ms + 하이브리드 슬립(OS sleep + 마지막 1.2ms busy-wait),
그리고 **절대 시각 스케줄**이라 오래 돌려도 타이밍이 안 밀림.

---

## 실행 (개발자용)
```
pip install -r requirements.txt
python run.py
```

## exe 만들기
- **자동(권장, GitHub Actions)**: 이 저장소에 push 하면 `build-windows-exe` 워크플로우가
  윈도우 exe 를 만들어 Actions → Artifacts 에 올립니다. (파이썬 설치 필요 없음)
- **로컬**: 파이썬이 깔린 윈도우에서 `build_exe.bat` → `dist/MacroPRO.exe`

## 저장 위치
- 자동저장·실행기록: `%APPDATA%\MacroPRO\` (autosave.json, history.db)

## 구조
```
run.py                  진입점
macropro/
  timing.py             밀리초 타이밍(perf_counter·winmm·하이브리드 슬립·절대 스케줄)
  keys.py               키/버튼 직렬화·조합키 파싱(옆버튼 포함)
  ime.py                한/영 IME 감지·전환(ctypes imm32)
  clipboard.py          클립보드 넣기(붙여넣기용, ctypes)
  winctl.py             창 조절(pygetwindow / ctypes EnumWindows)
  engine.py             입력 조작 + 눌린키 추적·모두 떼기 + 붙여넣기·창·이미지
  recorder.py           녹화(메모리 상한)
  player.py             재생(주기·반복·복구·IME·절대 스케줄·랜덤대기·이미지 건너뛰기)
  model.py              Macro / MacroSet / .m 파일(체인·예약·랜덤대기 포함)
  store.py              자동저장(JSON) + 실행기록(SQLite)
  ui/
    theme.py            색·폰트 토큰(웜 팔레트)
    widgets.py          둥근 버튼·카드·알약 위젯(Canvas)
    editor.py           동작 편집 창
    broadcast.py        📡 멀티 타겟 빌더
    history.py          📜 실행 기록 창
    app.py              메인 창(큐로 스레드 안전·예약·체인)
```
