# ▣ ChatGPT 에게 줄 프롬프트 (이 줄부터 끝까지 전부 복사해서 붙여넣으면 됨)

너는 Windows 데스크톱 **매크로 프로그램**의 시니어 설계자야.
아래에 내 프로그램의 **현재 구조와 기능**을 정리해 놨어. 이걸 다 파악한 다음,
**추가하면 좋을 신박하면서도 '일반 사용자가 진짜 쓰기 편한' 매크로 기능**을 뽑아줘.

### 뽑는 규칙
- **12~15개**. 뻔한 것 말고 **신박하지만 실용적인 것** 우선. (단, 공상 말고 이 구조에서 실제로 구현 가능한 것만.)
- 각 기능마다 **반드시 이 4가지**를 적어:
  1. **기능 이름** (한 줄, 이모지 1개 + 쉬운 한국어 이름)
  2. **Why? (왜 필요한가 — 길게)**: 사용자가 겪는 실제 불편/상황, 이게 없으면 뭐가 번거로운지, 이걸로 뭐가 좋아지는지. **구체적 사용 시나리오** 포함. 최소 4~6문장.
  3. **How? (어떻게 작동/구현하나 — 길게)**: UI에서 어떻게 보이고 조작하는지 + 내부적으로 어느 모듈·어떤 데이터(동작 dict 필드·설정 값)로 처리할지. 기존 부품(아래 구조)을 어떻게 재사용/확장하는지. 엣지 케이스·안전장치도. 최소 5~8문장.
  4. **난이도/빠른적용**: 쉬움·보통·어려움 + "이건 반나절", "이건 큰 작업" 식 한 줄.
- **설계 철학 지켜**: 하드코딩 목록 금지, **부품+값(파라미터) 조합 틀**로. 새 기능은 이름 하나 더 박기 전에 기존 부품의 값으로 되는지부터 따져. 실제로 뭘 할지는 사용자가 UI로 조합.
- 제약: **순수 Python + tkinter + pynput**(외부 서버·유료 API 없이). Windows 우선. 쓰는 사람은 **개발자 아님**(쉬운 말·버튼·값 채우기). "AI가 만든 티" 안 나게 자연스럽게.
- 마지막에 **"내가 꼽는 TOP 5 (이유 한 줄씩)"** 로 우선순위 추천까지.
- 전부 **한국어**로.

# 【현재 구조·기능 정리】

## 제품 한 줄
Windows 데스크톱 매크로 프로그램. 키보드/마우스를 밀리초 정밀로 녹화·재생.
여러 매크로를 만들어 단축키로 돌리고, 문구 타이핑/붙여넣기/이미지 조건/창 조절/
여러 방 동시 전송/예약·체인까지 된다. 순수 Python + tkinter + pynput, 외부 exe·서버 없음.

## 쓰는 사람 (핵심 맥락)
- 텔레그램 **업자 소통방 운영자**. 여러 방(채팅창)에 반복 공지·관리 작업을 자동화하려 함.
- 개발자 아님 → **쉬운 말, 버튼 위주, 설정은 값 채우기**. "AI가 만든 티" 안 나게 자연스러운 UX 원함.
- 요청 철학: **하드코딩 목록 금지, 부품+값(파라미터) 조합 틀**. 새 기능은 이름 하나 더 박지 말고
  기존 부품의 값으로 되는지부터. 실제로 뭘 할지는 사용자가 말로/UI로 조합.

## 설계 원칙 (지켜야 함)
- 동작 = 데이터(dict). 설정 = 값. 코드는 부품(실행기)만 제공.
- 밀리초 정밀: perf_counter + winmm timeBeginPeriod(1) + 하이브리드 슬립 + **절대 시각 스케줄**(드리프트 0).
- 스레드 안전: 재생/리스너(pynput)는 별 스레드 → **큐로 넘겨 메인스레드(_tick 90ms)에서만** tkinter 접근.
- 안전장치: 정지/종료 시 눌린 키·버튼 모두 떼기, 마우스 복구, DB atomic, 메모리 상한.
- 탐지 게임엔 쓰지 말라 경고(계정 정지). 일반 반복작업용.

## 코드 구조 (모듈)
```
run.py                 진입점(고해상 타이머 켜고 App 띄움)
macropro/
  timing.py            perf_counter·winmm·hrsleep(하이브리드)·Scheduler(절대시각)
  keys.py              pynput 키/버튼 ↔ dict 직렬화, 조합키 파싱(ctrl+c), 옆버튼(x1/x2)
  ime.py               한/영 IME 감지·전환(ctypes imm32) — 실행 중 영문 고정
  clipboard.py         클립보드에 글 넣기(ctypes CF_UNICODETEXT) — 붙여넣기용
  winctl.py            창 조절(pygetwindow / ctypes EnumWindows) 제목 일부로 찾기
  engine.py            실제 입력 조작 + 눌린키 추적·모두 떼기.
                       run_action(a) 가 동작 dict 하나 실행. 지원 타입:
                       move/mouse/scroll/key/click/type/paste/hotkey/image/
                       wait_image/if_image(조건 건너뛰기)/window/broadcast(여러 방)
  recorder.py          녹화(키·마우스·스크롤·이동, delay=앞 동작과 간격, 메모리 상한)
  player.py            재생 스레드. loops/speed/jitter/cycle/ime_lock/release_all/
                       restore_mouse/rand_min·max. 인덱스 루프(if_image 가 N개 건너뜀).
  model.py             Macro(name/actions/hotkey/loops/speed/chain/schedule) ·
                       MacroSet(전역설정) · .m 파일(JSON) · action_label(사람이 읽는 한 줄)
  store.py             자동저장(JSON, 앱 끄면 안 날아감) + 실행기록(SQLite)
  ui/
    theme.py           웜 팔레트 토큰 + 어두운 사이드바 색(Codex 느낌)
    widgets.py         RoundButton·Card·Pill·NavButton(사이드바 항목)·ScrollFrame(스크롤)
    editor.py          동작 편집 창(동작 추가/정렬/삭제, F8 좌표찍기, 🎯 연속찍기, 📡 멀티타겟)
    broadcast.py       📡 멀티 타겟 빌더(방 위치들 or 창 제목 + 공통 문구 → broadcast 동작)
    app.py             메인 창. 사이드바(📋 매크로/⚙ 전역설정/📜 기록/❓ 도움말) + 메인 페이지 전환.
                       F12 실행↔편집, F8 좌표, F9 녹화, F10 정지. 큐 기반 스레드 안전.
```

## 지금 있는 기능 (전부)
- 여러 매크로 관리: 추가/복사/삭제/순서, 매크로마다 실행 단축키·반복·배속.
- F12 실행↔편집 토글. 실행 모드에서 단축키로 매크로 발동.
- 녹화/재생: 키·마우스·스크롤·이동. 절대 스케줄이라 오래 돌려도 안 밀림.
- 동작 조립(편집기): 클릭 / 문구 타이핑 / 📋 붙여넣기(복사→Ctrl+V) / 단축키 / 이동 /
  대기 / 스크롤 / 🖼 이미지 보이면 클릭 / ⏳ 이미지 뜰 때까지 / 🔀 이미지 조건(없으면 N개 건너뛰기) /
  🪟 창 조절(제목으로 띄우기/이동/크기/최소·최대/닫기).
- 📡 멀티 타겟(여러 방): 좌표 또는 창 제목으로 여러 방에 [클릭→입력→엔터] 한 바퀴.
- 🎯 멀티 좌표 연속 찍기(F8 누를 때마다 클릭 동작 추가).
- ⏰ 매일 자동 실행(예약 HH:MM) · 🔗 매크로 체인(끝나면 다음, 무한루프 방지).
- 🎲 동작마다 랜덤 대기(더 사람같이) · 타이밍 랜덤 ±%.
- 한/영 IME 감지(영문 고정) · 종료 시 키 떼기·마우스 복구.
- 💾 .m 파일 저장/불러오기 · SQLite 자동저장 · 📜 실행 기록 보기.
- 밀리초 정밀 타이밍.

## 아직 없는 것 / 약점 (기회)
- 조건·반복 분기가 if_image(이미지)밖에 없음. "픽셀 색 보고", "창 있으면", "클립보드 값 보고" 같은 조건 없음.
- 변수·카운터 없음(예: N번 반복하며 번호 증가, 리스트 순회).
- 입력 소스가 고정 문구뿐. CSV/txt 목록을 줄마다 다른 값으로 돌리는 "메일머지"식 없음.
- 트리거가 단축키·시각뿐. "이 창 뜨면 자동 실행", "클립보드 바뀌면" 같은 이벤트 트리거 없음.
- 녹화 후 편집이 거칠음(동작 일괄 수정, 좌표 상대화, 특정 동작만 반복 등).
- 좌표가 절대값 → 창 위치 바뀌면 깨짐(창 기준 상대 좌표 없음).
- 실행 중 상태 가시성 약함(지금 몇 번째 동작인지, 진행바 등).
- 안전/실수 방지: 실행 전 미리보기·예행(드라이런), 긴급 중단 핫키 강조 등.
